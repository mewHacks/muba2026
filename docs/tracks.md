# Tracks

Judging (shared across all tracks): product UX, real-world readiness, technical implementation, presentation — plus "does it work" and "would anyone actually use it" (Thetanuts framing).

## Sui Track 01 — Payments & Stablecoins ($750 / $500 / $250)
Build the future of money movement on Sui.
- **Ideas:** campus payments, creator payouts & tipping, group expenses, merchant checkout/POS, remittance, payroll, stablecoin wallets, treasury, escrow.
- **Looking for:** real workflow, fast intuitive UX, effective Sui/stablecoin use, working live demo.
- **Helpful Sui features:** sponsored transactions, zkLogin, Programmable Transaction Blocks.

## Sui Track 02 — AI × Sui ($750 / $500 / $250)
Use Sui for ownership, identity, payments, or on-chain execution.
- **Ideas:** on-chain-wallet agents, transaction-executing assistants, workflow automation, agent-to-agent commerce, AI marketplaces, personal copilots with digital ownership.
- **Looking for:** AI solves a real problem, Sui is integral (not an add-on), thoughtful UX, working live demo.
- **Helpful Sui features:** zkLogin, Walrus/MemWal, Programmable Transaction Blocks, sponsored transactions.

## Thetanuts Track 01 — Best product on the SDK (1,000 USDC: 600/400)
Build any working product on the Thetanuts SDK (decentralized options protocol on Base).
- **Possibilities:** structured products, vaults, consumer trading apps, options-powered lending, analytics, or something new.
- **The bar:** a real working product that uses on-chain options *meaningfully*. Hard rule: if it would behave identically with the Thetanuts calls stubbed out, it doesn't count.
- **Resources:** `@thetanuts-finance/thetanuts-client`, docs.thetanuts.finance/sdk — see [thetanuts-sdk.md](thetanuts-sdk.md).

## Thetanuts Track 02 — AI × Options (1,000 USDC: 500/300/200)
Build an AI agent that places a real on-chain options trade via OptionBook or OptionFactory, **live on Base mainnet**.
- **Ideas:** natural-language trading, AI strategy/risk copilot, autonomous hedging agent.
- **The bar:** execute at least one real trade against live pricing — not paper trading, not testnet. Trade small (1–3 USDC is enough; scores the same as 100).
- **Resources:** Thetanuts MCP server (`@thetanuts-finance/mcp`), docs.thetanuts.finance/sdk — see [thetanuts-sdk.md](thetanuts-sdk.md).

One entry can take both Thetanuts tracks and win both.

Thetanuts workshop: 27 Aug, 8:00 PM, Google Meet — presenter Shawn Chee (Fullstack Developer).

> **Unofficial brainstorming steer (from mentor, not the deck):** SUI judge on product UX, real-world problem fit / PMF, technical implementation (favor *complete* over *complex*), security & privacy, and presentation. Underexplored angle: **real-world assets (RWA)** — few teams pitch RWA + options together, so that combo stands out. For Track 02 (AI × Options), aim for something that genuinely surprises a judge in what the agent can autonomously do, not just "chatbot that calls an API."

## Gonka Track — AI for Society (1,200 / 800 USDT + Top 10 get 20M tokens/month for 3–6 months)
Build AI tools with genuine public value using Gonka.
- **Open-ended directions:** AI fact checker, multilingual public assistant, accessibility tools, open knowledge engine.
- **Mandatory:** all AI reasoning/verification must run through Gonka Router at gonkarouter.io.
- **Preferred fact-checker shape:** input URL/text, multi-model cross-verification, Truth Score (0–100%) + reasoning trace, display Gonka Request IDs.
- **Submit:** live demo URL, documented GitHub repo, 2-minute live fact-check video.

Gonka Router workshop: 27 Aug, 9:00 PM, Google Meet — presenter Jack (Tech Lead).

> **Unofficial brainstorming steer (from mentor, not the deck):** judge on real-world problem fit / PMF and innovation/niche — avoid ideas that already exist in common Web3/AI solutions. The idea doesn't need to be on-chain, and doesn't need to be Malaysia-specific — a global social-good problem is fine, as long as it's genuine public value.
